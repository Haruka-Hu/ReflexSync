# 关键类与函数索引

核对日期：2026-10-19。这里列当前常用调用点；先读 [代码运行顺序](代码运行顺序.md)，再按功能定位源码。

## 1. Master

主体：[master_node.cpp](../lib/master_node/master_node.cpp)。

| 函数 | 谁触发 | 作用 |
| --- | --- | --- |
| MasterApp::begin | Arduino setup | 初始化硬件、队列与四个任务 |
| handlePcCommand | serialCommandTask | 处理 PING、同步、采集、STOP、无线与重发命令 |
| transitionTo | 命令处理 | 切换采集状态并准备开始时刻 |
| broadcastCommand / retryStateCommand | 状态切换／无线任务 | 同序号广播和限时重发 |
| handleSyncProbe | wirelessTask | 回复双向同步探针 |
| sensorTask | FreeRTOS | DRDY 后读取本地 48CH 样本 |
| serialTxTask | FreeRTOS | 合批 EMG、转发 IMU、服务诊断和 PC 缓存 |

ADS1298：[ads1298_48ch_driver.cpp](../lib/ads1298_48ch_driver/ads1298_48ch_driver.cpp)。begin 初始化；verifyAndRepair 校验／修复配置；readChannels 读取 6 颗器件并按逻辑通道映射输出。改通道数、PGA、RLD 或测试信号，应改顶部配置区并同步上位机换算参数。

## 2. Slave

主体：[imu_slave_node.cpp](../lib/imu_slave_node/imu_slave_node.cpp)。

| 函数 | 作用 |
| --- | --- |
| ImuSlaveApp::begin | 根据入口 Config 选择传感器并创建任务 |
| sensorTask | 处理定时通知、读取、组批、本地漏采 |
| readSensor | 根据 SensorMode 调用 readGyro 或 readSample |
| storeBatch / takeSendCandidate | 保存批次并挑选待发送／重传项 |
| sendPacket | 串行化发送并等待对应完成回调 |
| handleBeacon / sendSyncProbe / updateClockFit | 维护 Master 信息、双向同步和时钟拟合 |
| localToSampleTimeUs | 转成采样记录使用的时间轴 |
| updateRadioPower | 按当前状态应用接收窗口 |
| printDiagnostics | 输出温度、采样、队列、发送和同步指标 |

[clock_fit.h](../lib/imu_slave_node/clock_fit.h) 负责纯数学拟合；[sample_schedule.h](../lib/imu_slave_node/sample_schedule.h) 负责定时到期与漏采判定。驱动寄存器分别在 [mpu6500_driver.cpp](../lib/mpu6500_driver/mpu6500_driver.cpp) 和 [adxl375_driver.cpp](../lib/adxl375_driver/adxl375_driver.cpp)。

## 3. 采集上位机

主体：[scope48_mvc.py](../tools/scope48_mvc.py)。

| 类／函数 | 作用 |
| --- | --- |
| resolve_recording_dir / parse_args | 固定工程相对路径、解析运行参数 |
| AcquisitionModel | 采样、诊断与录制状态的共享模型 |
| SerialReader | 串口接收、帧校验、解析和控制命令 |
| EmgLiveFilter | EMG 显示滤波与幅值换算 |
| MvcTracker / MvcCalibration | RMS 反馈、标定阶段、参考值和百分比 |
| MainWindow.connect_serial / disconnect_serial | 手动连接／断开会话 |
| send_control_command | 发送采集命令并配合清空／停止录制 |
| toggle_recording / _finish_recording | 开始／停止录制并启动后台分析 |
| _analyze_recording_files | 转换、分析、生成波形 |
| _recording_waveform_path | 由 CSV 位置得到当前工程的波形目标 |

注意：start_recording 保存 EMG 原始 BIN；CSV 转换发生在停止后的分析路径，不能只凭录制时没有 EMG CSV 判断失败。

## 4. 电机固件

[main.cpp](../src/motor/main.cpp) 连接 USB/BLE、文本解析、队列与控制任务。

[MotionController](../src/motor/motion_controller.cpp)：

| 方法 | 作用 |
| --- | --- |
| zeroHere / home / jog | 当前静止点归零／接近靶面／手动移动 |
| setSettings / setTuning | 在允许状态下更新动作和控制参数 |
| start / retract / fire | 一键动作／回撤／从 READY 下击 |
| update | 用实际 dt 更新测速和状态机 |
| holdControl | 回撤与 READY 共用的位置保持控制 |
| endStrike / abortMotion / stop | 正常撤驱动结束／故障制动／用户停止 |
| recordTrace | 缓存当前击的时间、位置、速度与输出 |

[SpeedController](../src/motor/speed_controller.h) 是前馈加 PI；[SpeedDropDetector](../src/motor/speed_drop_detector.h) 用角度窗口和速度下降判断接触候选；[HallEncoder](../src/motor/hall_encoder.cpp) 负责四倍频计数与测速；[Drv8871Motor](../src/motor/drv8871_motor.cpp) 负责正反转、COAST 和 BRAKE 输出。

## 6. 协议与辅助

[capture_common.cpp](../lib/capture_common/capture_common.cpp) 中的 makeImuBatchPacket / decodeImuBatchPacket、buildPcEmg48BatchPacket、buildPcImuWirePacket 与 CRC 编解码，应与 PC 解析一起维护。

[scripts/upload_master_tinyusb.py](../scripts/upload_master_tinyusb.py) 只负责 Master 引导切换和调用上传，不参与运行时采集。[analyze_data.py](../tools/analyze_data.py)、[view_emg48.py](../tools/view_emg48.py)、[view_waveform.py](../tools/view_waveform.py) 是录制后的必要子程序。
