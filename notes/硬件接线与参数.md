# 硬件接线与参数

核对日期：2026-10-19。以下是当前源码配置，应与实际板卡核对后烧录。

## 1. 板卡与 USB

| 目标 | Flash / 内存配置 | USB 模式 / 串口速率 |
| --- | --- | --- |
| master | 8 MB Flash、`qio_opi`、启用 PSRAM | TinyUSB CDC，4,000,000 baud 配置值 |
| slave-01 / slave-02 | 4 MB Flash、`qio_qspi` | USB Serial/JTAG，115200 |
| motor | 16 MB Flash、8 MB Octal PSRAM，`qio_opi` | USB Serial/JTAG，115200 |

PlatformIO 的公共 board 名称是 `esp32-s3-devkitc-1`；具体 Flash 与内存由各环境覆盖。USB CDC 的 baud 参数不等同于 USB 总线实际吞吐。`slave-01/02-biger-buffer` 是额外的 16 MB Flash 环境，不适用于默认 4 MB SuperMini。

## 2. Master：6 × ADS1298

入口配置：[src/master/main.cpp](../src/master/main.cpp)。

| 信号 | GPIO |
| --- | --- |
| CS1…CS6 | 16、15、7、6、5、4 |
| MOSI / MISO / SCK | 11 / 13 / 12 |
| DRDY / RESET_N / START | 9 / 14 / 17 |

当前逻辑通道不是按 CS 顺序从 CH01 排列：

| CS | GPIO | 逻辑通道 |
| --- | --- | --- |
| CS1 | 16 | CH33–CH40 |
| CS2 | 15 | CH41–CH48 |
| CS3 | 7 | CH17–CH24 |
| CS4 | 6 | CH25–CH32 |
| CS5 | 5 | CH01–CH08 |
| CS6 | 4 | CH09–CH16 |

[驱动顶部配置](../lib/ads1298_48ch_driver/ads1298_48ch_driver.cpp) 当前为：48 通道、外部正常电极输入、关闭内部测试信号；CONFIG1=0x84，目标 2 kSPS。SPI Mode 1，配置 1 MHz，数据读取 8 MHz。

**增益核对：`NORMAL_CH_CONFIG=0x00` 对应 PGA 增益 6；上位机 `--ads-gain` 默认仍为 4。当前固件应使用 `pixi run scope48-mvc --ads-gain 6`。** 原始计数录制不受该显示换算参数影响，但 µV 显示和 MVC 标定中的幅值单位需要保持配置一致。固件改增益后，应同步调整启动参数并重新标定。

RLD 当前启用，以 CH01–CH08 为反馈源，P/N 输入均参与，输出位于逻辑块 0（CS5 对应的 ADS）。这只是寄存器配置说明，不能替代实际电极、PCB 和 RLD 接线检查。

## 3. 两个 Slave

| 项目 | slave-01 | slave-02 |
| --- | --- | --- |
| 传感器 | MPU6500 | ADXL375 |
| source | 0x01 | 0x02 |
| CS / MOSI / MISO / SCK | 10 / 11 / 13 / 12 | 相同 |
| INT | 未接，配置 -1 | 未接 |
| SPI | Mode 0，配置 1 MHz、读取 8 MHz | Mode 3，2 MHz |
| CPU | 80 MHz | 80 MHz |
| 主机输出 | 三轴角速度原始计数，约 1000/s | 三轴加速度原始计数，约 1000/s |
| 传感器 FIFO | 未使用 | Bypass，FIFO_CTL=0x00 |

MPU6500 的角速度量程寄存器为 0x18；ADXL375 校验设备 ID 0xE5，BW_RATE=0x0E，即内部 1600 Hz 更新。ESP32 每 1 ms 读取最新值，两次读取之间被覆盖的芯片样本不会上传。

加速度方案不提供全部 1600 Hz 原始流，也没有在此直接读取环节加入抗混叠滤波；不能保证捕获任意短时冲击峰值。未接 INT 时，读取时间戳与芯片采样相位仍有约一个内部采样周期的不确定性。原始计数不要未经校准就当作精确 g 值。

无线默认信道 1、2 Mbps；发射功率请求值 84 qdBm，SDK 实际施加的值由 `NODE_DIAG tx_qdbm` 确认。接收窗口为每 50 ms 接收 20 ms；SPI 读取与无线接收窗口是两个不同机制。
