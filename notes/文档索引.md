## 当前入口

```bash
# 当前固件 NORMAL_CH_CONFIG=0x00，对应 PGA 增益 6
pixi run scope48-mvc --ads-gain 6
pixi run motor-host
```

上位机只有这两个入口；tools 中其余六个文件是运行依赖。测试、诊断、串口 CLI 和旧上位机不再是当前任务。

## 文档与历史的边界

旧温度实测、早期电机方案、PCB 设想、学习课程和本机清理清单已备份到仓库外。它们不用于描述当前配置，也不随公开源码上传。

当前源码与本目录文档是工作入口；历史实测不应被当作当前所有板卡的验收结果。发布检查是编译和离线软件检查，不能替代机械、供电或实机通信验收。
