# 加速度双峰与肌电波形提取

脚本只需要同一时段采集的 EMG 和 IMU CSV，不需要电机日志。它把相邻的两个加速度峰尝试配成一组，使用**后峰的上升沿作为接触候选**，再检查后峰附近是否有肌电变化。所有判断均需看图复核，不能自动确认生理反射。

在项目根目录运行，替换输入路径：

```bash
pixi run reflex-extract \
  --emg "data/emg48_capture_20261027_133618.csv" \
  --imu "data/imu_capture_20261027_133618.csv" \
  --out "outputs/我的波形提取"
```

`--out` 必须是尚不存在的目录。中文路径如果 Pixi 激活失败，可在命令前加 `LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8`。

默认绘制前 3 组通过初筛的肌电变化候选；若没有通过的候选，则画前 3 组供复核。`paired_candidates.csv` 列出所有配对结果：

- `id`：双峰组编号；`first_peak_s`、`second_peak_s`：两峰相对肌电第一条设备时间戳的时间；`pair_gap_ms`：两峰间隔。
- `contact`：后峰上升沿候选时间；`responding_channels`：肌电达到变化阈值的通道数；`onset_candidate_ms`：这些通道首次越阈时间的中位数。
- `assessment`：`emg_change_candidate` 表示双峰和肌电变化通过简单初筛；`review_ambiguous` 表示有肌电变化但存在需检查的标记；`review_no_clear_emg` 表示未达到肌电变化筛选条件。**三种均不代表生理诊断或已确认有效叩击**。
- `flags`：采样间隔异常、起始贴近搜索边界、未找到后峰上升沿或前峰落在肌电基线等情况。`unpaired_peaks.csv` 保存未配对加速度峰及原因，防止漏看。

查看候选表后，可以指定组号绘图，必须使用新的输出目录：

```bash
pixi run reflex-extract --emg "肌电.csv" --imu "加速度.csv" \
  --events 1 2 3 --out "outputs/选出的三次"
```

已有人工确定的接触候选时刻，也可以直接输入相对 EMG 首条设备时间戳的秒数：

```bash
pixi run reflex-extract --emg "肌电.csv" --imu "加速度.csv" \
  --contact-s 12.203706 118.749090 138.886867 --out "outputs/手动时刻"
```

默认设置为加速度峰高度至少 80 counts，峰检测最短间隔 100 ms，按时间顺序将相邻峰在 80–250 ms 内贪心配对；一次配对使用的峰不再参与其他配对。使用 `--threshold`、`--min-gap-ms`、`--pair-min-ms`、`--pair-max-ms` 可以调整。注意峰检测最短间隔会先限制能进入配对的峰。不同实验的峰幅和间隔可能不同；任何配对参数变化都可能改变组号。配对错乱、相邻峰数量不是两个、或间隔过大时，检查未配对峰并调整参数或手动选时刻。

默认至少 `--min-channels 12` 个通道出现肌电变化才算通过初筛。阈值不是临床标准，也不能证明信号不是共同伪影；请根据具体实验调整并逐击看波形。`--imu-offset-ms` 可输入**已通过外部测量确定**的加速度时间修正量，正数表示加速度时间向后移动；默认零。完整选项可用 `pixi run reflex-extract --help` 查看。

## 输出与时序

每组 PNG 上方是加速度变化，下方是三组肌电中位数；左侧为完整窗口，右侧放大叩击附近。黄色虚线是前峰，黑线是后峰接触候选，红线是自动肌电起始候选。每组另输出独立肌电及加速度窗口 CSV：保留原始列、设备时间戳、相对毫秒；肌电另含 48 列展示滤波结果。两路各保留原有采样点，不重采样。

检测肌电使用二阶因果 20–450 Hz 带通、3 ms 后向 RMS，以后峰接触候选前 −500 至 −200 ms 为基线，在 5–100 ms 搜索持续 3 ms 超过基线均值 +3 SD 的首次时刻。图上的肌电使用四阶 20–450 Hz 加 50 Hz 陷波，与检测滤波不同。起始靠近 5 ms 搜索边界的组标记为复核。

EMG 输入需要 `timestamp_us` 和 `ch01`–`ch48`，采样率 2 kHz；IMU 需要 `timestamp_us,x,y,z`，若有 `source` 列则读取 `Accel`。两路设备时间戳必须已经映射到同一时钟基准，脚本不自动估计同步误差。32 位计数器回绕可处理；记录应属于同一时段。滤波延迟、机械传递、运动伪影和同步偏差均可能影响结果，不能把自动越阈数或平均值直接当作确认的腱反射潜伏期。
